商家可以在后台自定义上架各类服务套餐，设置服务价格、规格、赔付规则、交付时效，例如单局撤离护航、全天包车、王牌上分、新手教学等。玩家在任意一端进入平台，都可以浏览服务、下单支付，填写游戏大区、角色信息、需求备注；同时支持客服后台录单，承接微信私域成交的订单，统一录入系统归档，避免漏单、错单。订单状态实时流转，待接单、进行中、待验收、售后纠纷一目了然，玩家可以随时查看打手上传的战绩截图、进度报备。

派单模式支持管事定向指派和打手抢单大厅两种模式。打手入驻需要提交段位、战绩材料，管理员审核通过后方可解锁接单权限。打手接单后可以上传阶段性战绩，完工提交验收凭证，玩家或管事确认验收后，系统自动核算平台抽成与打手佣金，打手可在线查看收益明细、提交提现申请，财务在后台统一审核打款。同时支持配置炸单赔付规则，遇到掉分、任务失败等情况，后台留存全部订单凭证，方便售后仲裁。

底层继承 LikeShop 丰富的营销工具，优惠券、限时活动、分销推广、会员体系均可直接启用。可以设置渠道推广奖励，打手、客服、老客户分享链接，新用户下单即可获得佣金，助力社群裂变。消息通知复用公众号模板消息、小程序订阅消息，下单提醒、接单通知、验收通知、提现结果实时推送。
